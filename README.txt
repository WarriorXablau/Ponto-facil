PONTO FÁCIL — PROJETO PWA INICIAL

Conteúdo: index.html (calculadora), manifest.webmanifest (instalação), service-worker.js (cache offline), icons/icon.svg (ícone).

TESTE: a instalação PWA exige HTTPS (ou localhost). Hospede todos os arquivos mantendo as pastas. Abra o endereço no Chrome/Android e use o menu para Instalar app/Adicionar à tela inicial.

GOOGLE PLAY: depois de hospedar e testar, o projeto pode ser empacotado para Android via Trusted Web Activity ou Capacitor. Também será necessário preparar política de privacidade, ficha da loja, imagens e conta Google Play Console. A publicação depende de aprovação do Google.
